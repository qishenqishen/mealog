# Mealog pastel keepsakes · 2026-09-12

Original artwork generated with the built-in `image_gen` tool, based on the user's pale, finely stippled illustration references. Each PNG contains one fruit, drink, utensil or small object on a transparent background. The palette spans blush, peach, butter yellow, sage, mint, powder blue and lavender.

The app uses 384px PNGs with their alpha preserved. Tool originals remain at the paths recorded in the manifests; resizing is the only packaging operation. The original keepsake set remains in `../final` for reference and is no longer used by the app.

Full prompts and generation provenance:

- [Apple prompt](prompts-apple.json)
- [Starter, meals and rhythm prompts](prompts-starter-meals-rhythm.json)
- [People, photographs and notes prompts](prompts-people-photos-notes.json)
- [Feelings, rare and secret prompts](prompts-feelings-rare.json)

Validation: 57 distinct transparent assets, 6.46 MB total; all original keys covered. The complete checks are recorded in [asset-check.json](asset-check.json). Two darker variants (blueberry and plum) were regenerated paler; both original outputs remain documented in the manifests.

Filenames retain the 57 existing artwork keys so achievement rules, stored progress, and secret-placeholder selection remain unchanged. Artwork subjects are decorative keepsake motifs; they do not change achievement titles or conditions. The app's live mapping is `src/constants/keepsakeArt.ts`.

Reference source notes and the six untouched screenshots are in the Mealog aesthetics knowledge base: `产品迭代/2026-09-12-淡彩颗粒收藏图标.md` (REF-005).
