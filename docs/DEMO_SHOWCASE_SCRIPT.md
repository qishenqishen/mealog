# Mealog Showcase Script

This is a short phone-demo path for showing the complete Mealog product loop.

## Prepare

1. Open Profile.
2. Tap `Prepare showcase table`.
3. When the confirmation appears, open Home or Archive.

The seed writes real local data through the same storage paths as the app:

- meals
- meal photos
- notes
- moods
- reusable people profiles
- meal companions
- shared meal photos
- keepsake progress

It uses fixed `demo-*` IDs, so tapping the button again updates the same showcase set instead of creating endless duplicate meals.

## Five-Minute Demo Flow

1. Start with Home and show the monthly table illustration, date strip, meal hotspot, and chair hotspot.
2. Scroll into the lower Home section to show Catering and Seats Around the Table.
3. Open Add and save a small new meal memory.
4. Open the new meal detail and show photo, title, time, location, moods, company, shared photos, and note.
5. Open Archive. Switch between Calendar and Memories to show the monthly memory wall.
6. Open People and show reusable companions and shared meal history.
7. Open Insights and frame it as a gentle reflection, not analytics.
8. Open Collection and show keepsake families, progress, unlocked states, and detail sheet.

## What This Demo Proves

- The app works without sign-in.
- It can record a meal end to end.
- It can preserve people and shared-meal context.
- It can show month memory, archive, reflection, and keepsake systems from real stored data.
- It is ready for Expo Go testing and EAS preview build preparation.
