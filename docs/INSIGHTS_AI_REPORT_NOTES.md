# Monthly AI Insights

Insights generates a report only after the user presses Generate. The hosted app sends an allowlisted monthly text payload to its same-origin Cloudflare Worker, which calls Workers AI model `@cf/meta/llama-3.1-8b-instruct-fast` using JSON Mode. Provider metadata is `cloudflare_workers_ai`.

The server computes meal, day, note, photo-presence, mood, type and companionship counts from validated input. AI writes the reflection and cites supplied meal IDs; it does not supply aggregate metrics. A bounded sample of meal text supports the narrative. References open the original meal. Local people and shared-meal counts open person profiles without sending contact profiles to AI.

English and Chinese reports are cached locally by source (personal/sample), month, language and a stable input snapshot. Legacy meals without an origin remain personal; edited samples are already marked user records by storage. Old unscoped cache entries remain readable but are not presented as source-specific reports. Content version 2 adds concrete, gentle paragraphs and explicitly excludes diagnoses, inferred closeness, forced positivity, advice, and invented sensory details. Old report content versions and changed shared input are marked stale. Errors preserve saved reports and deterministic metrics. No automatic generation or replacement narrative runs when AI fails.

Meal notes are excluded by default; the user can opt in before generation. The payload uses a maximum of 240 characters per note with visible disclosure. Counts in the screen always use the full local selected table, even when notes are excluded from the AI input. The model receives compact evidence entries (ID, title, note, mood and company tags), not photo-presence hints or precomputed statistical tables. Richer notes are preferred within chronological buckets; the 4 KiB budget can result in a smaller evidence sample.

The new **In your own words** field is a separate local list at `@mealogue/monthlyReflections/v1`, keyed by month and personal/sample scope. It never enters the monthly AI payload or AI cache. Writes use the existing per-key lock and rollback helpers, report failures, and preserve unsaved drafts in the mounted page. Empty text deletes that month's thought. Full data clearing includes the new key. This is not cloud backup.

Live QA exposed an awkward Chinese literal rendering of dumpling-making and occasional English-only titles. Chinese output now uses a localized neutral heading if necessary and narrowly normalizes plural viewpoint, that known idiom and ending punctuation. These are presentation corrections, not a rule-generated replacement narrative; failed generation still returns an error. Original journal text is untouched. Free-form prose can still contain mistakes, and the current model can be terse; this is not a proven general hallucination filter.

Meal text and notes may contain personal information. Photos, GPS fields and contact profiles stay on the device; the worker accepts only the documented fields and does not log or persist request bodies. One SQLite Durable Object stores quota counters and salted IP hashes: 50 global generation attempts per UTC day and 3 attempts per IP per 10 minutes. Failed provider calls count, too. AI calls have a server abort signal after 30 seconds; client requests time out after 45 seconds.

See [worker integration notes](../worker/INTEGRATION.md) for schemas, scripts, cache deletion integration, limits, and verification details. No account upgrade is performed. Billing-subscription inspection was denied by the current OAuth scope; the implementation does not claim to have verified the account's billing plan. Keep the account on Workers Free for platform-enforced no-overage behavior. Other apps on the same account can consume its shared free allocation.
